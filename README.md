# skills

Claude Code skills. Install one by copying its folder into `~/.claude/skills/`.

- `deepen`: turn a task into a more rigorous version of itself (expert practice, raw material, methods, independent validation), then a Jim Gray review and a plan, ending with a question before implementing.
- `deepen-auto`: the same, but implements the plan straight away.

`deepen/jim-gray-library/CATALOG.md` lists the papers the Jim Gray review reads; the copies themselves are not in this repo (download them into `raw/` and `text/` locally).
